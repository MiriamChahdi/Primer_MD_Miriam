# Detalles del Equipo Tridimensional

## Especificaciones del Equipo de Maniobras (EDM)

El equipo utilizado por el Capitán Levi incluye:

* Doble propulsor de gas comprimido a alta presión.
* Cuchillas de acero superendurecido intercambiables.
* Arneses reforzados para soporte corporal completo.
